# Don't Stop · 视觉系统

本轮保留像素角色、枪械轮廓、地图结构与 410 × 230 逻辑视口，把玩家可见界面统一为深色金属与暖金标识。主菜单让营地场景成为画面主体；营地、属性和设置优先保证操作与信息辨识。所有尺寸以下均指逻辑像素。

| 入场 | 220 ms cubic ease-out，始终从可见状态开始 |

统一实现位于 `ui/GildedTheme.gd`。购买、升级、出发等主要操作使用暖金实色；卸下、移出等操作保持普通按钮。悬停、焦点、按下、禁用状态分别定义。保留价格、付款方式、真实属性与未装备状态，不制造展示数值。

## 武器与战斗

- 武器原始像素图以整数比例显示；展示底座、稀有度标记、手持 HUD 使用同一身份色。
- 电弧使用线圈电流，轨道枪的双导轨电容读取真实蓄力，引力武器使用交错约束环，热能与重火力使用散热鳍片、弹仓与供弹结构。装饰贴合机械部件，减少悬浮光点；转管运动仍由真实转速驱动。
- 枪口包含短促亮芯与局部柔光。枪身回弹使用稳定握持锚点，避免夸张压扁。
- 命中碎光只由实际扣血触发，同一目标 75 ms 内合并，最多同时 32 个，220 ms 后释放。装饰不调用随机数接口，不参与碰撞、伤害或物理。
- 保留原有敌方预警、伤害轮廓与战争迷雾。降低闪光选项抑制新增闪光；环境光放在地面之上、角色与攻击标记之下。

## 场景与 HUD

场景使用已有真实灯光，辅以共享径向纹理制作的低强度呼吸反射光、稀疏尘粒和边缘暗化。静态墙体增加接触阴影与下沿反光，不改变任何碰撞矩形。

战斗区域的静态地面与墙体按原有绘制顺序生成一个有顶点色的 ArrayMesh，继续接收正常 Canvas 灯光，不使用低分辨率烘焙贴图。地面接缝、铆钉、环形嵌线与墙体前立面体现区域材质；前立面收在原碰撞轮廓之内。角色投影统一置于角色和预警下方，伤害数字统一置于战斗反馈层，并继续由原目标负责释放。

预警亮度单向推进，取消临近触发时的快速闪烁；射击源使用有方向的短促火舌，爆炸使用快速扩张与缓慢消退。范围、触发时刻和持续时间继续由原玩法逻辑决定。

Web loader 与原生 Boot 共用像素字标、暖金分隔线、深色底和相同画面比例。进度来自实际下载、初始化与场景交接，不设置最低等待时间。修改武器绘制方式后，必须用新浏览器验证首次开火：外观原本使用过的 Canvas shader 变体也属于首次使用预算。

HUD 固定在屏幕边缘。左上承载生命与经济信息，右上承载遭遇信息，中上为 Boss 阶段，底部为七槽与弹药；战斗中心留给瞄准与敌方预警。

状态、升级提示与弹药读数透底，以细描边保证文字辨识。Boss 面板收紧高度、降低底色不透明度；实色血条即时读取 HP，失血残影短暂停留后追上，持续命中不重置整个滞留期。

奖励、复活与结算使用居中的完整面板和统一暗幕。余额、描述、费用与按钮都收在面板内部；奖励卡的鼠标悬停和键盘焦点提供相同说明。结算按标签与右对齐数值排版，关卡信息归入面板，生存时间显示为分秒。

爆炸先释放快速压力波，再留下稀疏暖色碎屑；减弱大块填色。装饰沿已有墙体裁剪轮廓展开，保留真实范围边界、240 ms 生命周期、装饰数量上限与降低闪光设置。连续通知共享可取消的过渡，旧提示不能关闭新提示。

以真实运行截图、交互回归和性能对照作为工程证据；截图或自动检查不替代玩家对审美和手感的主观认可。
