# Don't Stop 深度品质迭代 · 2026-10-04

基线：`main` / `origin/main` = `2174cd17071191e344cbefd1524610dfea091aa0`。本地分支：`codex/deep-combat-quality`。交付为本地候选版；未推送、部署或发布。

## 结果与边界

本轮落实材质与墙体接触细节、枪械内部机械动作、敌人蓄力与弹体方向、Boss 状态读数和结算节奏；同时减少重复 A* 搜索、伤害数字 Tween 分配和敌弹碰撞形状分配。没有降低敌人、弹幕、反馈数量或修改武器数值、Boss 阈值、存档协议。

功能与规则检查通过；**不能据此声称整体性能已经全面提升，也不能把本轮标为“无回归的代际升级”**。早期 4K / Web 测量有明显退化样本。最终姿态优化后的复测另列，保留全部有效与无效样本。共享机器负载会影响计时，但尚未证明它是所有差异的原因。

## 当前源码审计与取舍

从启动、营地、战斗、地图/寻路、枪械与弹体、敌人与四位 Boss、HUD/结算到持久化/退出链路检查当前实现，并运行相应原生场景与浏览器流程。结构图覆盖不足的 GDScript 采用直接源码检查。证据目录提供运行时代码哈希清单；它是版本定位清单，不代表每一行均经过人工证明。第三方插件未进行逐行审计。

优先解决已实测/有具体设计依据的问题：整枪缩放让金属机匣显得柔软；危险源与攻击方向连接不足；地图已有区域身份但表面细节与接触层次弱；大量相同端点的 A* 请求重复分配完整路径；每个伤害数字创建 Tween 及四个 Tweener。保留现有移动、碰撞、射速、RNG 和反馈上限。

## 实际验证

- Godot **4.7.2** 导入、Web Release、Windows x64 Release 成功；Windows 运行实际导出 EXE/PCK。测试数据隔离于 `output/deep-iteration/*/userdata-tests`，浏览器使用独立 profile。
- **25 个无错误完成的原生场景，1057 个断言**；涵盖保存、基础回归、武器姿态、营地、摄像机、碰撞/出生、压力约束、RNG、生命周期、地图与四位 Boss。最新修改后 `DeepQuality` 34/34。较早的完整场景结果不是全部对最终二进制重跑，具体来源见 JSON。
- Windows 已实际进入营地并操作移动；完整战斗覆盖主要由真实引擎/真实武器的自动化场景完成，**不冒充人工无辅助通关**。四位 Boss 都覆盖阶段 II/III、大招与清场；观察角色使用 400 HP，全套武器，不是正常难度成绩。
- Web 实际输入覆盖购买 W6、射击、冲刺、进入战斗、装填、暂停阻断、设置、回营、连续开局和重新载入 durable 存档。常规与 4K 流程通过；4K 驱动确认 RX 7900 XT 硬件加速，无页面/引擎/网络错误。首枪四个采样窗口 before/after 最大帧均约 **16.8 ms**，没有复现旧报告的首枪尖峰。
- 压测 D：stage 39、seed 20260918、完整 45 秒；Windows/Web 各 1920×1080 与 3840×2160。压力 P：真实移动、射击、击杀/补充，目标 180 敌人，4K 有效稳态 90 秒。未减少负载参数；因现有实例/帧节奏影响，击杀轨迹并非逐帧相同。
- `stress-completion.test.js` 12 个检查、浏览器驱动语法检查及 `git diff --check` 通过。

可明确归因的局部收益：同进程交替六轮、4080 次/轮的固定端点热缓存微基准，A* 每请求中位数 **28.50 → 2.36 µs（约 -92%）**。实际主矩阵每请求约为原生 **6.72 → 2.89 µs**、Web **16.91 → 8.87 µs**。每个伤害数字少分配 **1 Tween + 4 Tweener**；例如原生 D 的 2506 个数字对应 Tween 创建数 **0**。这些不能换算成整体 FPS 提升；节点创建率、碰撞移动与出生热点仍存在。

## 已知限制与未通过项

- **整体尾帧收益尚未证明**；共享 CPU/GPU 负载未完全隔离。不能以“其他进程可能繁忙”直接解释或豁免变慢结果。
- 用户提出改用 Codex 内置浏览器后，自动化连接两次均在创建内核资源时失败：`系统找不到指定的路径 (os error 3)`；标签页请求 queued 不等于实际测试成功。已有 Web 证据来自独立 Playwright Chromium。
- `B15Weapons` 七个断言虽通过，但退出报告 4 个资源仍被引用；用原版 PCK 重现同样问题，未计入 25 个干净场景。真实 Windows 退出的 ObjectDB 警告在前后版本均存在（样本为 19–21 个）；运行压力段 orphan 峰值为 0，二者不能混为“所有泄漏已修复”。
- 没有做正常血量四 Boss 人工通关、数小时耐久测试、其他硬件验证、远端 CI 或线上部署验收。最终美术品质仍需用户实际游玩判断。
