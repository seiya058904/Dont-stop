# B9 evidence index — Normal driver calibration and balance re-measurement

Everything in this directory was produced by the frozen instrument listed in `freeze.sha256`.
No file in this directory is hand-written except this index, `freeze.sha256` (generated by
`tools/b9-freeze.ps1`) and `summary.json` (generated by `tools/b9-summary.py`).

## The one question this round answers

B8 measured Normal Stage 22/26/29 clear rates with a driver whose 16-direction danger
evaluation sat behind `if target_boss and target.is_boss` in `tests/M8Runtime.gd`. The Boss
driver dodged incoming attacks; the Stage 21–29 driver walked into them. So the B8 clear rates
were an underestimate of what the build can do, and they must not be the basis for another
product nerf.

B9 extracts that evaluation into one shared core (`M8Runtime.choose_safe_movement`) that both
paths call, and re-measures the SAME product with the SAME fixture.

## What the driver is allowed to do

`choose_safe_movement()` reads real state only — the player's own collider via `test_move`, the
live monster list, the live hostile zones, the live enemy shots, the real line-of-sight ray —
and returns a direction that the caller turns into real WASD presses through `Input.action_press`.
There is no teleport, no invulnerability, no HP edit, no deleted projectile, no deleted zone and
no forced kill anywhere in it. It is invoked once per movement decision (10 Hz), not per physics
frame, so the bot cannot out-react a person.
