# Don't Stop

This directory contains the Godot 4 project source for Don't Stop.

See the [repository README](../README.md) for the browser build, Windows release, controls, credits, and source information.

## Local play

Double-click [`PLAY_GAME.bat`](PLAY_GAME.bat) to export the current source with a local Godot 4.7.2 runtime (`%GODOT%`, `%GODOT_EXE%`, the legacy local path, or `D:\tools\godot\4.7.2\Godot_v4.7.2-stable_win64.exe`) and start a local Windows Release build. For a packaged product, use the [latest Windows release](https://github.com/seiya058904/Dont-stop/releases/latest).

The game source, tests, and project assets are kept in this directory; generated exports and editor state are local build products.
