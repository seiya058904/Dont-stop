# Don't Stop

Don't Stop is a top-down 2D survival shooter/roguelite built with Godot 4. Fight through encounters, collect weapons and upgrades, and return to camp to shape the next run.

## Play

- [Play in the browser](https://seiya058904.github.io/Dont-stop/)
- [Latest Windows release](https://github.com/seiya058904/Dont-stop/releases/latest)

## Controls

WASD/arrow keys move, the mouse aims, and left click fires. `R` reloads, `Shift` dashes, `1`–`7` switch weapons, and `E`/`Tab` opens the camp or loadout.
