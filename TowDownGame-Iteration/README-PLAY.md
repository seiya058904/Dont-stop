# TowDownGame · M3—M4 H2候选

**启动：双击本目录 `PLAY_GAME.bat`。** 使用工作区已有 portable Godot 4.7.2，无需全局安装；首次启动导入资源。未制作新的独立Game.exe或导出ZIP。

营地购买、装配和升级 → 出发战斗 → 结算回营 → 再次整备。新档金币/天赋点均9999，旧档保持已消费余额；「出发/补给 → 试玩补充资源」可补到至少9999。存档仍隔离于原版。

## 本轮新增体验

- **24把枪**：保留13把，加入反弹、一次裂片、三枚散射火箭、双追踪导弹、三束棱镜、松手蓄力贯穿、瞬时扇面、固定tick热流、聚拢后爆炸、出回锯盘、加速转管。
- **24种配件**：同型号可购买多个实例。支持枪械分类/名称或计划编号搜索、已拥有、配件槽位与兼容当前枪筛选；购买保留商店页并定位新实例，装配后查看完整机制参数。
- **24个计划持久天赋**：可任选金币或天赋点购买，显示等级、上限、当前/下一档与触发条件。旧头盔/蓝靴作为T07/T08历史来源保留；其他8种独特原型持久奖励另保留，金币/回血一次性物品不计天赋。
- 天赋页「重置计划天赋 / 查看退款」按记录的真实付款返还。旧档无记录的计划等级在确认前显示数量，不能精确退款；取消保留配置，确认才清除。原型历史来源不在此次重置范围内。

## 合并 H1 / H2 试玩路线

1. 「枪械」页搜 W17/W18/W19/W20，买入装备；「出发/补给」选单靶/三靶或正常45秒遭遇。
2. 比较棱镜与原激光：棱镜一次三束；轨道炮按住蓄力、松开发射；扇面为单次宽冲击，热流按住连续近程喷射。
3. 试引力聚拢与结尾爆炸、锯盘的出回两段、转管从稀到密的弹流。切枪、暂停、换弹和回营时观察动作收尾。
4. 试四类搭配：能量/贯穿（W13+贯穿弹芯+T13）；爆炸/击杀联动（W19+扩爆+T16）；反弹/裂片（W17+反弹弹壳，或W18+贯穿）；持续射击/装填回填（W24+散热器+回填器+T11）。不是所有机制都兼容同一配件，详情会说明。
5. 用两种货币分别升级，查看首发/护盾/连杀等状态，再打开重置预览比较配置。退出重开核对枪械、实例、弹药、天赋和付款记录。
6. 同时补验暂缓的H1：移动/冲刺、视野、0.12秒切枪与原激光手感，以及人耳音量、最终长文字布局。

WASD/方向键移动，鼠标瞄准，左键射击，R装填，Shift冲刺，数字1—7仍对应持有栏前7把，**Tab可访问全部24把**，营地E整备，原榴弹配件仍为右键。菜单滚动不切枪；关闭菜单后需松开射击键再开火，沿用原保护。

A11/A13仅适用于有宽度判定的新束流；原激光的中心射线/tick机制保留，不假装给它增加可调判定宽度。T21已实现精英条件，当前R1没有新增精英/Boss，不适用于Boss。
