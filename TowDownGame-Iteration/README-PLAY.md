## 第二次试玩重点

1. 回营后直接点击「买枪 / 买弹匣 / 装配件 / 升天赋 / 出发」。Tab或E打开整备页。
2. 一级导航中「武器 / 配件 / 弹匣补给 / 天赋 / 出发 / 装备」独立显示，当前分类高亮。
3. 武器左侧列表显示名称、Tier、类型、价格和拥有状态。默认Tier低到高，可搜索、筛Tier/类型，按Tier强度或价格排序。右侧核心卡固定，长属性默认折叠；底部购买/装备按钮始终留在详情滚动区外。
4. 「弹匣补给」直接购买+5/+10/+25备用弹匣，分别10/18/40金币，显示当前和购买后数量。HUD左侧是当前枪内子弹，右侧是备用MAGS。
5. 每次完成换弹消耗1个备用弹匣，将当前枪补满；手动提前换弹同样消耗1个。满弹不消耗，取消换弹不扣库存。换枪和卸下扩容配件不会产生备用弹匣。
6. 24个配件全部可用于24把枪，保留槽位和实例所有权。同槽替换会把旧件放回背包。详情展示真实前后属性，不再研究兼容清单；原专用效果保留时，另外提供明确通用增益。
7. 24枪固定Tier I—V，价格区间分别60—120、260—380、650—850、1400—1800、2800—3600金币。高Tier有更强实际火力和有限枪口/尾迹/命中反馈，不是随机稀有度。
8. 普通敌人命中的基础压力降低12.5%，Boss本体轻调3%；HP和遭遇数量未增加，没有难度选择菜单。普通遭遇生存45秒，Boss击杀后结算。

## 钱包、存档与操作

当前为试玩版：新档9999金币、9999天赋点、10个备用弹匣。每次启动时，旧档钱包也补到至少9999；高于9999不扣减。本次游玩中购买正常扣款，普通保存/读取不会反复补钱。

退出：打开设置，点击底部固定的「退出游戏」，或关闭窗口。营地先保存再退出；战斗尚未结算或保存失败时，可取消退出，或明确放弃本次未保存变化后退出。

schema1—4旧档按原装备枪的旧容量，将备用子弹向上换算为整弹匣；无装备时以30发为换算单位。只在迁移时换算，schema5保存reserve_magazines，后续加载不再转换。容量规则变化导致的超容量枪内子弹会夹到新上限，不返还或复制备用弹匣。配件实例、装备归属、合法钱包和付款/退款记录保留。

WASD/方向键移动，鼠标瞄准，左键射击，R换弹，Shift冲刺；数字1—7对应前7把持有枪，Tab可访问全部武器；旧榴弹配件仍用右键。关闭菜单后先松开射击键再开火。

内容保持24枪/24配件/24持久天赋、12普通敌人/3Boss、6区域/30遭遇。推荐重试普通关6/8/13/17/24和Boss10/20/30，关注购买便利、弹匣持续性、Tier差异、配件收益、压力及危险预告可读性。
