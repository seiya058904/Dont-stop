# TowDownGame · M5 完整战斗试玩

**启动：双击本目录 `PLAY_GAME.bat`。** 使用工作区已有 portable Godot 4.7.2；首次启动导入资源。没有新的独立 Game.exe 或导出 ZIP。

营地购买 / 装配 / 天赋 → 选择遭遇 → 战斗 → 结算回营 → 再次整备。每轮仍返回营地。

## 本轮可玩内容

- 12种普通敌人：保留追击、蜂群、预警冲锋、喷射；加入破甲重冲锋、自爆、有限生产/分裂、限额治疗、正面盾、精确直射/炮击、侧绕短扑和死亡对敌连爆。
- 3个Boss：第10轮破城机甲（破甲、冲击、扇扫、护卫）；第20轮蜂巢聚合体（召唤、扇弹、脉冲）；第30轮棱镜核心（侧移、扫射束、环弹）。都有半血阶段和恢复窗口，击杀才胜利，没有倒计时自动通关。
- 6区、30正式遭遇：R1原街区保留，货运场、冷却站、处理区、能源走廊、核心平台采用真实墙体和不同通路/刷怪方向的灰盒布局；不是最终美术。
- 原24枪、24配件、24计划持久天赋保留。精英猎手现在可在第5/15/25轮末段的显式精英上发挥作用，Boss不适用。

## 直接体验路线

1. 营地「出发/补给」按六区分组查看全部30轮，任意点击「开始此遭遇」。直接试玩不跳过正常进度；默认继续按钮显示真正的下一关。
2. 先试6/8轮的破甲与远程组合、12轮正面盾与侧翼、13轮精确射线与炮击、17轮支援后排、18/24轮连爆与分裂。
3. 用反弹/裂片试冷却站短墙；用爆炸/引力试处理区；用轨道/高速弹道试能源走廊。再直达10、20、30轮比较三个Boss。
4. 普通轮生存45秒，Boss轮击杀后结算。正常通关第30轮后可回营重玩，也可从第1轮再次出发；不会读取第31轮。
5. 合并补验暂缓的H1：移动/冲刺、视野、0.12秒切枪、原激光、真实声音和长文字布局。

WASD/方向键移动，鼠标瞄准，左键射击，R装填，Shift冲刺，数字1—7对应持有栏前7把；**Tab可访问全部武器**，营地E整备，原榴弹配件仍为右键。菜单滚动不切枪，关菜单后需松开射击键再开火。

## 成长与保存

新档金币/天赋点均9999；旧档保持余额、装备、配件实例和天赋，营地可补充资源。金币购买装备，金币或天赋点单币升级天赋。天赋重置按记录的真实币种/金额返还；旧档缺记录部分在确认前提示，不猜历史付款。

schema4新增明确的正常通关记录；旧档兼容、不重复发资源、不改变已有下一关。试玩第30轮不会伪装成正常通关。

## 验收边界

H1_STATUS = DEFERRED_BY_USER；HUMAN_ACCEPTED = false。M3—M4为用户指定的ENGINEERING ACCEPTED，不等于真人认可。

本轮使用headless、关闭渲染的SubViewport和独立存档；未操作桌面或启动可见游戏窗口。最终画面、声音、键盘手感仍待真人验收。后台循环时间不能代表GPU帧率；合成极限压力未达到参考帧时间预算。此前GPU残留及部分短测音频退出诊断继续保留，详见 `docs/iteration/VALIDATION.md`。最终阶段状态见 `STATUS.md`。

没有匹配导出模板，不升级引擎、不以旧Game.exe冒充新包。M5结束后停止，不自动进入M6。
