# TowDownGame · M2-R1 体验增强版

**启动：双击本目录 `PLAY_GAME.bat`。** 使用工作区已有 portable Godot 4.7.2，无需全局安装。首次启动会导入资源。

本次交付为可玩的本地开发入口，尚未制作 Windows 独立导出 ZIP。存档隔离在 Godot 的 `TowDownGame-Iteration` 用户目录，不读取原版 Don't Stop 存档。

## H1 试玩路线（约 5 分钟）

1. 开始游戏，查看金币/天赋点；需要恢复充裕余额时用「出发/补给 → 试玩补充资源」。
2. 买原激光 BoomBoi、新电弧、等离子或三连发。第二把起购买只拥有，点击「装备到手中」。
3. 为电弧买「电弧中继」，在「当前配置」选择配件实例安装。核对后跳 3 → 4；切其他枪需先在配置中选择目标枪。旧拖拽背包仍可用。
4. 分别用金币、天赋点升级天赋，看两种余额与当前等级。先试基础配置，再叠加连杀、爆破、修复。
5. 「出发/补给」选择街口接敌、远程交错、蜂群冲锋。每轮45秒，胜利后回营地；失败可复活或带着装备返回。
6. 射击中用 Tab 打开配置，检查伤害停止；设置叠在配置上时，Esc 只关一层。退出重开核对装配与余额。

WASD/方向键移动，鼠标瞄准，左键射击，R 装填，Shift 冲刺，1—7 快捷选枪，Tab 配置，营地 E 整备。营地练枪靶不奖励经验/掉落。原榴弹配件仍使用右键。

## 这次有什么

- 15种配件：原9种 + 指定6种新配件；同型号可买多份实例。
- 6种本阶段完整展示/升级的计划天赋；原10种持久奖励与2种一次性补给另外保留。
- 4种敌人、1个改良区域、3个遭遇；本阶段没有新增 Boss。

阶段状态、验证边界与已知问题见 `docs/iteration/STATUS.md`、`VALIDATION.md`。完整24枪/24配件/24天赋/12敌人/3 Boss/6区/30遭遇留待 H1/H2 后续阶段。

**READY FOR HUMAN REVIEW**。重点反馈：移动是否保持、轮廓/视野是否舒服、原激光是否保留感觉、新枪差异和装配说明是否清楚。自动化与截图不代表用户已认可手感或声音。

## M2-R1 试玩补充

本轮保持13枪、15种配件、6种计划持久天赋、4种敌人、R1三个遭遇。HUMAN_ACCEPTED=false。

- 「枪械」页按编号列出全部13把，拥有后可直接装备；数字键1—7继续对应持有栏前7把。新切枪去抖0.12秒，同枪按钮不打断动作，HUD动画独立。
- 配件购买后自动定位到新实例；先在当前配置选目标枪，再看装配前后数值和旧件返回背包的说明。
- 出发/补给提供单靶、三靶和清理。伤害说明区分每弹、每弹丸、三发一组、激光tick与电弧递减后跳；没有标称“真实DPS”。
- 营地旧传送门与「继续下一关」都按正常进度出发。只有点选某遭遇的直接试玩按钮才进入试玩，试玩不推进正常关卡。
- 购买完成但磁盘保存失败时，面板显示未保存，可点「重试保存」，不会再扣款。退出失败会提供重试、取消或明确放弃变化。
- 坏档不会被临时试玩覆盖。恢复面板可导出原文、重试读取，或明确建立新体验档（先备份原文件）。旧档恢复不重发9999或一次性金币/回血奖励。
- 声音按Music/SFX/UI分组，总音量覆盖全部；原激光时序保持0.1秒tick/0.4秒窗口。请H1实际试听并比较切枪前后感觉。


## 本轮交付说明

M2-R1保留当前内容规模与营地循环。切枪输入由1.1秒改为0.12秒，其他移动/冲刺/相机参数保持；天赋详情展示实际累计效果及下一等级。保存检查写入、flush、替换与回读；上一快照保存在存档旁的`.previous`文件，回读损坏时尝试恢复。失败重试只保存当前状态，不重新购买。

本轮仍以工作区`PLAY_GAME.bat`交付，没有匹配的本地Windows导出模板，因此没有伪造独立预览包。该入口使用相对路径找到现有portable；不需要改PATH或安装新Godot。

已完成的真实窗口检查见VALIDATION。按用户要求，后续验证停止Windows Use，改用无窗口夹具；原生键盘、最终详情布局与人耳音效继续标为未确认。首轮GPU长测的两次临时实体残留未定因，保留为同环境复验事项；后台测试不替代这项证据。
