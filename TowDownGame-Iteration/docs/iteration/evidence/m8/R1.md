## 性能原始数字与判定

新规则：p95 或 p99 **绝对增加 >8ms，或相对增加 >20% 且绝对增加 >2ms**，任一即 `review_needed=true`。2ms 是小基数噪声门槛；+11ms/+30% 不会被 35% 阈值吞掉。六项 Python 回归覆盖历史例子、绝对/相对单独越界、噪声、改善及仅 p95 越界。
