# 08 敌人组合与Boss

## 设计目的

敌人是展示武器和成长价值的对象，不是为了增加难度而增加血条。大部分遭遇保持清怪连贯；特殊敌人让玩家短暂调整瞄准、站位和目标优先级，而不是持续打断操作。

完整目标12种普通/特殊角色（含保留的主流程Monster2），另3个Boss。换色/增加血量的精英修饰不算一个新角色。先盘点未使用素材和场景，能完整复用就复用，但“资源存在”不等于“行为已实现”。

## 12种角色

| ID | 职责 | 行为与弱点 | 反馈和约束 |
|---|---|---|---|
| E01 原型追击者 | 基线近战 | 保留原Monster2主要节奏，修复移动/攻击/死亡问题 | 保留辨认特征，作为新枪对照 |
| E02 轻型蜂群 | 成群清理 | 小体型、低生命、群体涌入，短接触攻击 | 提供成片击杀，不从脚下瞬刷 |
| E03 重甲破坏者 | 重火力目标 | 较慢、可破甲，破甲后明显更易击杀 | 护甲反馈有裂痕/闪光，不做纯高血量木桩 |
| E04 预警冲锋者 | 短促位移威胁 | 瞄准→清楚预警约0.6秒→固定方向冲刺→恢复 | 冲刺中不全程追踪转向；撞墙有恢复窗口 |
| E05 远程喷射者 | 优先击杀目标 | 停下蓄势，射出可见实体弹，再移动 | 不在不可见处连续命中；弹速留反应空间 |
| E06 自爆逼近者 | 近身空间威胁 | 靠近后短时明显闪烁/音效再爆，提前击杀可阻止敌对爆炸 | 不无预警瞬爆，范围与提示对应 |
| E07 分裂母体 | 范围武器收益 | 死亡生成有限小体，子体不再次分裂 | 数量上限及死亡代次受控，不能无穷刷怪 |
| E08 支援治疗者 | 目标优先级 | 脆弱，间歇给少量附近敌人治疗，治疗链可见 | 不自我无敌、不形成无限互疗；同一目标回复封顶 |
| E09 正面盾卫 | 改变攻击角度 | 正面减伤、侧后弱点，重火力可破盾 | 盾角度清楚，不100%免疫让多数枪无效 |
| E10 标记炮击者 | 地面预警 | 发射前明确标地面，延迟落点，不能预测玩家未来位置 | 危险区域优先显示；最多有限同时标记 |
| E11 侧绕猎手 | 横向移动 | 在有限范围侧绕靠近，再进入近战 | 不是完美躲弹AI；速度不骤增，不把玩家堵死 |
| E12 易爆载能体 | 连锁清场目标 | 脆弱载体，死亡产生对附近敌人有利于清场的爆破 | 和E06区别明显；死亡连爆按队列和上限，不递归爆栈 |

攻击预警时间是首轮体验值，可按本地速度/视角调整；不能把时间调到几乎看不见来“提升难度”。小怪单体基础生命优先参考原型前期清怪节奏，而非统一乘十。

## 精英修饰

允许对现有角色加一个可读精英修饰，如更大、少量护甲或一次强化攻击。不叠多个看不懂的词缀，不默认伤害加倍。精英明显但不是全屏都精英；掉落/击杀表现有所提升。

## Boss B01：破城机甲（第10轮）

主题是重武器打击与破甲。以已有可适配素材组合，不引入完全不同画风。

循环：预警直线冲击→恢复露出弱点→扇形短程扫击→释放少量普通敌人供清理。半血后节奏略变化，但不新增不可见机制。至少一次清楚破甲反馈；保护玩家有持续输出窗口。

验收：冲锋不会穿墙/越出场地，所有攻击有前摇，破甲阶段与视觉一致，死亡只结算一次，附属敌人/弹体全部清理。Boss不能因导航卡住变成永远打不到的目标。

## Boss B02：蜂巢聚合体（第20轮）

主题是群体清理和目标优先级。间歇召唤E02/E07，另有慢速扇形弹和脉冲区域；小怪阶段结束有输出恢复窗口。

召唤数量和频率受控，总活跃敌人有上限；Boss不能借小怪层层叠加遮住自己。清掉召唤目标应帮助玩家，而不是召得更快来惩罚击杀。

验收：召唤上限在最弱配置下也不会失控；链电、裂片、爆炸在密集阶段仍稳定；Boss死后不再有延迟召唤。

## Boss B03：棱镜核心（第30轮）

主题是能量武器和战斗高潮。预告后做可见的扫射光束、慢速能量环和侧边召唤；每轮攻击间留可移动和持续射击窗口。

预告射线与真实伤害线分清；激光不是瞬间无预警转向玩家；场地保留足够走位空间，不用黑暗或摄像机锁死增加难度。半血后组合加快但不把空隙归零。

验收：光束起止、墙体遮挡、暂停、死亡、回营地全正确；连续激光音不残留；通关后有完整结算和重新选择区域入口，不访问第31轮不存在的数据。

## 通用移动与生成

选择现有Godot导航或参考模板AStar思路中最适配的最小实现。先证明原区绕墙有效，再批量增加场景；不要为每只怪每帧重建整张网格。

生成点必须在可行走区域、到玩家可达，并与玩家保持最低安全距离。新怪可在屏幕外合理边缘生成，但不得凭空贴身出现；屏内生成要有短预告。记录生成失败重试上限，不在失败时死循环找点。

敌人数量增加时做轻量分离与拥挤处理，不能彼此叠在同一像素里，也不能用很大碰撞体把玩家入口堵死。被击退的对象不得进入墙内或传送区。

## M2 最小阵容

E01基线、E02蜂群、E04冲锋、E05喷射者，组成一段可循环的战斗；新增3个角色即可验证数量、预警和远近组合，不等到12种全部完成才让用户试玩。
