# 06 配件目录、兼容性与装配规则

## 24种目标的组成

保留原注册的9种配件：QuickdrawMagazine、UniversalExtendedMagazines、ExtendedRifleMagazine、QuickExpansionMagazine、ShotgunShellPouch、MachineGunMagazine、SubmachineGunMagazine、SuperUniversalMagazine、GrenadeLauncher。[S02]

先审计其实际生效范围、装卸可逆性和描述；资源存在不等于已经能正确装配。保留原ID，不把注册表缺号当成需要补齐的Bug。

以下增加15种，使总目标达到24。新增物品必须支持多个实例，每个实例只属于背包或某一枪的某一槽；不能同时出现在两把枪上。原八个槽作为兼容骨架，避免另造重复的装配系统。

## 不兼容时怎么办

卡片显示明确原因，例如“需要链式武器”“当前槽被另一配件占用”“此枪无可调整散布”。不兼容配件可以购买到背包，但不能一边提示已装备一边没有效果。

同槽替换采用：预览新旧变化→移出旧件回背包→装入新件→从基础重算→一次发布变更。任一步失败恢复原配置；不能简单覆盖字典然后把旧节点留在枪上。

## 禁止重复效果和状态残留

复制/重进场景不能多次连接同一个加成信号；卸装/卖出（本轮不做出售）不能撤掉其他同类来源。不能通过反复装卸刷满弹匣或永久加速。

测试至少覆盖：两个同型号实例、两把枪来回换、同槽替换、快速连续点击、战斗暂停装配、装填中取消/拒绝装配策略、保存恢复、已装对象缺失时的恢复。

营地作为主要配装入口，同时保留原型的战斗暂停后装配能力。修改前必须暂停战斗、取消或完成旧射击/装填动作，再原子重算并验证，不能恢复后由旧回调覆盖新配置。若当前实现暂不能安全支持，应将其标为尚未完成的回归项，而不是悄悄永久删除原有功能。
