# 04 视野、打击感、音频与成长界面

## 1. 解除视野阻碍，保留美术

在临时原型副本记录同位置截图后，追踪 `Main.tscn` 的CanvasModulate、Town中的实例灯光/遮挡器、角色灯光、屏幕shader与Camera参数。不要把所有黑暗效果都叫战争迷雾，也不要只修改一个数值便宣布完成。

体验版默认采用“清晰战场”：视口内主要可行走地形、敌人轮廓、掉落和敌方攻击始终可读。保留夜景色调、场景阴影、枪口亮光、激光和爆炸照明。装饰阴影可以存在，但不能让普通敌人因为不在玩家光圈内就难以辨认。

第一轮只调整环境可见性，不同时大改缩放、角色大小、移动速度和后处理。确需调整Camera时独立提供原值与新值，并在H1对比。攻击信息不能依赖默认不可见的屏幕外发射者；屏幕边缘威胁须有提前提示或只在合理视域中开始远程攻击。

不能把CanvasModulate直接强行改纯白当唯一方案；使用场景配色对照校验，避免泛白、失去发光层次。Boss的大范围特效不能重新形成遮挡全屏的另一种迷雾。

## 2. 战斗反馈分层

### 普通开火

按枪保留不同节奏、枪口闪光/射束起始、枪体局部反冲与音色。局部动画优先于推动玩家；普通枪不要影响用户认可的移动控制。停止开火、换弹、切枪后相应循环音和持续光束及时结束。

### 命中

敌人短闪、轻微形变、受力方向、接触火花/能量交汇点和命中音同时描述同一次事件。参考模板的flash/缩放恢复，但不要直接照搬其0.5秒曲线到高速射击。建议首轮视觉闪白约0.05–0.10秒，连续命中刷新受控，不永久白块。

暴击应有可识别的形状/字样/动画，不只换颜色。连续激光伤害可在0.15–0.30秒的显示窗口聚合，伤害结算tick不因此变慢或变快；普通伤害和暴击分别聚合。

### 击杀与范围清场

明确死亡姿态、碎片/消散、击杀音与掉落反馈。死亡对象不继续攻击；残留短暂且有数量上限。小怪批量死亡时合并部分装饰效果，但保留每次击杀的真实结算。

爆炸先短促爆心，再冲击扩散，再收尾粒子；视觉范围与实际伤害范围大体一致。连锁在源目标和后续目标之间显示路径，让玩家看懂为何一次开火杀了多个目标。

### 强事件与镜头

默认普通命中不做全局hit-stop。精英/Boss死亡或极重攻击可试用极短的视觉停顿，但必须有总频率限制、设置开关、暂停优先和自动恢复；无法证明不卡顿就不用。不能每个小怪死亡暂停世界，导致爽游变慢。

震屏、闪光、屏幕扭曲分别可调。默认中低镜头扰动、强局部表现；玩家把震屏设为0后仍能通过声音、敌人受击和弹道辨认强度。不要将Bloom强度和屏幕亮度无限叠高。

## 3. 音频必须能被听见和检验

将Master/Music/SFX/UI分开；保留原音乐并允许关闭，不默认删除。玩家主武器、换弹、空仓提示和关键危险提示优先，远处同类死亡音可限频。

可以参考模板SoundManager的独立播放和复用方法，不照搬无上限扩容。优先选择有限多音播放器或有限声部池；避免给同一个正在发声的播放器不断换stream导致打断。Godot的max_polyphony达到上限会切掉最早声音，设置stream也会停止现有播放，参见[S22]。

持续光束用开始/持续/结束三段或等价结构；切枪、回营地和暂停停止持续段。爆炸使用有限并发，不能因大量击杀让玩家枪声和换弹声消失。

验收至少包含30秒连射、混合枪同时命中、边缘位置、静音后恢复、切枪中断光束。Headless使用Dummy音频驱动，只能验证事件与资源，不能证明实际可听效果；声音是否舒服需真人听。

## 4. 商店：购买前、购买时、购买后

沿用像素风，不把界面重做成普通网页管理后台。调整间距、字体、卡片信息密度、图标和操作反馈，使鼠标使用清楚。

体验版提供全部已实现商品的分类页，默认可直接浏览；可保留原随机推荐区，但不得把新品藏在随机刷新之后才能测试。枪械、配件、天赋三个页签共享可见的钱包区域。

商品卡有名称、图标、类型/主机制、价格、拥有/未拥有、可购买/满级/不兼容状态。未实现内容不能显示成可购买的正常商品。

枪械详情说明弹道、伤害单位、射速、弹匣、装填和特色；不要只显示价格。配件详情展示能装哪类枪、哪个槽、当前枪的预览变化、若已占槽将替换什么。天赋显示当前等级、最大等级、本级效果和下一等级变化。

交易成功的提示应具体，例如：

```text
已购买「棱镜扩散器」· 40金币
状态：未装备
[装备到当前兼容武器]  [打开配件背包]
```

```text
已装备：离子喷射器 → 枪口槽
光束宽度 8 → 11.2；每tick伤害 10 → 9
替换下来的配件已返回背包
```

示例数值仅演示文案格式，真实面板必须从同一有效属性计算器获得。不支持的武器不显示诱导性的绿色升级箭头。

## 5. 装配与天赋信息

保留原拖拽，增加鼠标点击选择→明确安装按钮。既能熟练拖，也能让第一次玩的人不猜操作。查看槽位时能看到空槽、已装配件、兼容提示、卸下和替换；替换先显示新旧变化，不悄悄销毁旧件。

战斗HUD显示当前枪、弹匣/备弹、关键装配图标和有效天赋摘要。完整信息放在暂停/背包里的“当前配置”，不是把24个大图标铺满屏幕。

天赋详情显示名称、等级/上限、何时触发、当前是否满足条件；例如“连杀加速：当前2层，剩余3.1秒”，不是只给一个不解释的图标。普通常驻加成无需每帧弹提示。

明确区分持久天赋、暂时Buff、一次性回血/金币物品。一次性物品消耗后进入简短获得记录，不伪装成永久装备；有永久效果但只在购买时应用一次的条目仍必须保留持久记录。

## 6. 可扩展但紧凑的导航

保留数字键已有选枪体验；24把全买后不能出现超出屏幕的单行武器条。保留实际InputMap中已有数字键快捷入口，其他拥有武器在紧凑选择面板/滚轮入口可达；可让用户将常用枪放入快捷槽，界面说明快捷槽不等于拥有上限。不要未经检查把原有1–7快捷键缩减成1–6。

鼠标滚轮切枪若与菜单滚动冲突，则菜单打开时只滚列表，不切枪。打开菜单的同一输入不穿透为开火/购买。Esc只关闭最上层，最后才恢复战斗。

首次进入营地用短提示说明移动、开火、装填、冲刺、背包和商店；根据当前InputMap生成按键提示，不把猜测的Shift/Space硬编码。不要新增多页强制教学。

## 7. 体验版完成度补齐

营地有清楚的当前关卡/下一关、试玩关卡选择、购买和出发入口。出发前允许快速试射，目标场景限于一小块安全练枪区域，不做第二套产品模式。练枪不消耗真实关卡的胜利状态，也不把假人击杀当通关收益。

设置至少包含窗口/全屏、Master/Music/SFX、震屏强度、降低闪光。沿用现有设置能力，缺什么补什么，不为此移植整个参考项目菜单系统。

UI检查1920×1080与1280×720、窗口缩放、中文长名称、极端余额、24枪全拥有、满级天赋、长配件说明。继承原项目实际字体资源，不私自换成无法显示中文的字体。
