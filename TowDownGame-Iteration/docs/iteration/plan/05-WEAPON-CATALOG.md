# 05 枪械目录与制作规格

## 目标和计数

完整目标24把：保留原有10个注册项，并增加14把。原型注册项包括 `GunSprite`、`ShotgunBlaster`、`Sniper`、`BabyZapZap`、`AlienRifle`、`EmpireShotgun`、`BoomBoi`、`AlienMachine`、`RebalShotgun`、`Uzi`；这些是资源标识，不替换为未经核对的中文商品名。[S02][S19]

逐把运行，记录实际中文名称、弹道、射速、装填、弹匣、枪口/命中特效和声音。现有枪有缺陷时修复，不能删除一把再用新枪顶数。新增ID使用独立命名空间，兼容现有数字ID的保存映射。

以下14个是本计划的新增产品设计，不是已存在的实现。名称可做一致性的中文润色，机制不能不说明就删掉。若基线实际已有完全相同机制，记录证据并将该新位改为有实质区别的变体；不重复计数。

## 每把枪必须有的元数据

稳定ID、中文名、商品图、枪体图/动画、武器族、主机制标签、基础参数、弹药消费规则、适配槽位/配件标签、价格档、声音、开火/命中/击杀VFX、预算级别和一条可执行验收用例。

参数先依据用户喜欢的原枪建立量纲，不盲目把网上游戏的伤害值搬进来。下列目标数/弹跳数是起步规格；伤害与速度以同一测试敌人的击杀节奏校准，不做24枪完全等DPS的竞技平衡。

## 枪械族与兼容

沿用现有ASSAULT_RIFLES、SHOTGUNS、LASER_WEAPONS等类型字符串，在其上增加少量机制标签如 `beam`、`projectile`、`explosive`、`chain`、`charged`、`pellet`、`homing`。配件判断通过已定义标签，不按枪名包含“激光”猜测。

现有类型拼写存在历史形式时，通过兼容映射处理；不能改一个枚举名后让旧配件全部失效。

## 射击与强度的默认体验目标

普通小怪应快速死亡，使清怪连贯；精英允许集中火力，Boss依靠阶段和预警而不是巨额血条。新枪可以有明显强项，不需把所有输出压成同一数字。无限/充裕钱包不等于所有增益同时开启才是默认测试；分别测试基础枪、典型搭配和合法高叠加三档。

先让原有代表枪的击杀节奏不变，再调新枪和新敌人的相对关系。若Bug修复改变激光伤害，记录新旧原因，不能偷偷通过压低其他枪来“平衡”。

## 单枪验收卡模板

- 营地能正常购买、拥有状态正确，首次装备有明确提示。
- 空枪/满弹/剩1发/开火中切枪/换弹中切枪/按住射击暂停再恢复正确。
- 至少一个普通敌人、一个精英、一个墙体、一个密集敌群场景验证。
- 基础、至少一个兼容配件、至少一个天赋组合可对照显示与伤害日志。
- 离开遭遇无残留计时器、危险判定、循环音和孤立节点增长。
- 截图或短录屏能辨认该枪的独立打法；不是只有商品名不同。

## M2 首批选择

第一切片新增 W12跃迁电弧、W14等离子榴炮、W23三连发卡宾，覆盖链式、范围、普通实体弹三条可复用能力；同时保留并回归原型射线激光。不要一开始同时做14条不同攻击链。

M3之后按普通实体/分裂反弹→能量/蓄力→持续/特殊控制的依赖顺序扩展，详见里程碑。后续可以复用底层模块，但最终表现和使用策略必须不同。
